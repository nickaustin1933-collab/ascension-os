# Ascension OS Downloads

The source bundle in this folder contains the complete Android-ready project.

The installable `app-release.apk` is produced by GitHub Actions because this development container does not include the Android SDK. It contains the web app assets locally and does not need a network connection at runtime. Download it from the `ascension-os-offline-release-apk` artifact on the Android Release APK workflow run.

The app identifies its developer as `Jhondurd3n`.
